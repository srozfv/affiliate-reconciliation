# Запуск Ledger

Распакуйте архив полностью и откройте dist/index.html. Установка и вход не нужны. Для HTTP-запуска выполните npm start и откройте http://127.0.0.1:4178.

Интерфейс открывается на английском. Переключатель English / Русский расположен внизу слева. Смена языка сохраняет даты, партнёра и поиск.

Данные охватывают 1 апреля — 24 ноября 2026 года. FTD from / FTD to ограничивают финансовый период. As of задаёт дату, на которую известны события и статусы. Для просмотра месяца выберите его начало и конец.

В Review queue найдите CASE_REVERSED и нажмите Inspect: карточка показывает более раннее approved и последующее reversed. В CASE_LAST_CLICK показана ошибка атрибуции. CASE_HOLD иллюстрирует обязательство на hold. CASE_APRIL_OPENING и CASE_CURRENT_DAY позволяют проверить границы доступного периода.

В Sources скачайте четыре образца CSV. Загрузите их одновременно. Если один файл неверный, прежний набор сохранится. После обновления страницы снова откроется встроенный набор.

Команды разработчика: npm ci, npm test, npm run generate, npm run report. Для своих CSV: node scripts/report.cjs /путь/к/папке 2026-11-24.
